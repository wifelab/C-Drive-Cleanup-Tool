【磁盘清理大师（DiskViz）使用说明】

1. 双击「磁盘清理大师.exe」启动
   - 第一次运行 Windows 可能提示"未知发布者/已保护你的电脑"
     -> 点「更多信息」->「仍要运行」
2. 浏览器自动打开界面后，点「开始扫描」等待分析完成
3. 功能：
   - 中间「推荐删除」：一键清理临时/缓存文件（完全无用的）
   - 右侧分区：大文件 / 无用文件 / 重要文件 / 游戏存档 / 桌面文件 / 回收站
   - 删除时二选一：应用回收站（可撤回）或 Windows 系统回收站
4. 清理 C:\Windows 下的文件需要管理员：右键本程序 -> 以管理员身份运行
5. 本软件完全本地运行：不联网、不消耗 token、不上传任何数据

数据位置：本文件夹下的 .trash（应用回收站）
