# 🧭 DiskViz 磁盘可视化清理助手

扫描系统盘（C 盘），用量块树图可视化空间占用，自动筛出无用文件、自动标注重要文件，支持安全删除与一键撤回。

## 运行方法

1. **双击 `start.bat`**（需要本机已安装 Node.js）
2. 浏览器自动打开 `http://127.0.0.1:4173`
3. 点击 **▶ 开始扫描**，等待全盘分析完成（首次扫描 C 盘可能需要几分钟到十几分钟，页面有实时进度）
4. 也可以手动启动：在文件夹地址栏输入 `cmd` 回车，运行 `node server.js`

> 换端口：`set PORT=8080` 后运行 `node server.js`
> 只扫某个目录：`set SCAN_ROOT=D:\xxx` 后运行 `node server.js`

## 功能

| 功能 | 说明 |
|---|---|
| 🧹 推荐删除（主视图） | 扫描后主区域直接列出**完全无用的临时/缓存文件**（Temp、Prefetch、缩略图缓存、浏览器缓存、npm/pnpm 缓存、崩溃转储等），显示可释放总量，支持勾选/全选/**一键清理全部** |
| 🗃️ 大文件 | 自动列出全盘最大的文件（>1MB，Top 5000），按大小排序 |
| ⭐ 重要文件 / 🎮 游戏存档 / 🖥️ 桌面文件 | 独立分区：重要文件按类别分组；游戏存档（Steam userdata / My Games / Saved Games / UE SaveGames 等）与桌面文件各自成区，不受数量限制 |
| 🗑️ 安全删除（二选一） | 每次删除都让你选择：**① 应用回收站**（软件内 `.trash`，可撤回、可撤销上一步）或 **② Windows 系统回收站**（桌面回收站可见，本软件无法撤销） |
| ↩️ 撤回 | 对"应用回收站"的删除，一键撤销上一步 / 逐项恢复 |
| 🧨 清空回收站 | 仅针对应用回收站，需手动确认"永久删除" |

## 安全机制（重要）

- **受保护路径不可删**：`C:\` 根、`C:\Windows`、`Program Files`、`ProgramData`、回收站本身、本程序目录等——对这些路径的删除请求会被后端直接拒绝
- **删除一律先进回收站**：文件移到程序目录下的 `.trash` 文件夹，原路径恢复不依赖任何系统 API，随时可还原
- **恢复冲突自动改名**：原位置已存在同名文件时，自动改为"文件名 (已恢复).扩展名"
- **只在明确安全的区域标记垃圾**：垃圾识别是保守白名单（缓存/临时目录 + 特定扩展名），绝不建议删除系统文件、程序文件
- **权限不足不硬删**：被占用/无权限的文件会明确报错（如 `C:\Windows\Temp` 部分文件可能需要管理员）

## 技术说明

- 纯 Node.js 内置模块，**零第三方依赖**，离线可用
- 扫描引擎：有界并发（48 路）异步遍历，跳过符号链接（防止目录环），无权限目录静默跳过
- 数据保存在内存中，扫描完成后推荐删除列表、各分区面板都是秒开


## 目录结构

```
disk-visualizer/
├─ start.bat            # 双击启动
├─ server.js            # 后端：扫描引擎 + 识别规则 + 回收站 API
├─ public/index.html    # 前端：树图 + 面板（零依赖单文件）
└─ .trash/              # 应用内回收站（删除的文件在这里，清空=永久删除）
```
警告：作为初版，此软件的自动文件分类功能和推荐删除功能还很不完善，需要操作者自行甄别
